Questions

Frequently asked

Do I need to install anything?

No. It runs in any browser and installs as an app (PWA) on phones and laptops. Once installed it works offline for viewing.

Can it make Gujarat DEO / Patrak reports?

Yes — Patrak A/B/K for Primary, Secondary and Higher-Secondary, plus five inspection registers, in Gujarati and English, ready to print or download as Excel.

How does the substitute finder work?

When a teacher is absent, it lists free teachers ranked by subject match — same subject first, then secondary, then backup, then anyone available — so you assign the best cover in seconds.

Can I run more than one school?

Yes. The owner control panel lets you add unlimited schools, set each one's price, mark paid/unpaid, activate/suspend, and see activity — all from one login.

Which languages are supported?

Twelve, including English, ગુજરાતી and हिन्दी.
